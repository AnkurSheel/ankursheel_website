The main focus of this update was making WordXplorer much more intuitive and approachable for kids.

## Building a Main Menu

Until now, there simply wasn't a main menu. You opened the app and you were already in the game.

That's fine when you're testing your own build over and over, but it's not how a real game should feel. So this update adds a main menu. You can finally quit the game — no more force-closing the game.

<?# ResponsiveYouTube hXNdodt3M34 Title="Main Menu Video" /?>

I also used this as an excuse to experiment with Unity's UI Toolkit instead of the old uGUI setup. It lays things out with flexbox under the hood, which is a lot more intuitive for me than wrangling anchors and pivots. If you've done any web dev, it'll feel familiar. Styling works through USS, which is basically CSS with a different name, and layout is defined in UXML instead of hand-placed RectTransforms.

It's also supposed to have other benefits so I guess thats nice too.

## What's Next
